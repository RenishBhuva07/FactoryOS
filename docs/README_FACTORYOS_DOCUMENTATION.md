# FactoryOS Documentation Pack

This pack contains the 17 Markdown documents currently available for the FactoryOS product blueprint.

## Recommended project placement

- Put engineering/product reference documents in `docs/`.
- Put `05_GOOGLE_STITCH_PROMPT.md` in `stitch/` (or keep a copy in `docs/` if your workflow requires all references together).
- Put `13_ANTIGRAVITY_AGENT_INSTRUCTIONS.md` in `docs/` and create a short root `AGENTS.md` that points to the canonical documents.

## Canonical guidance

- Product scope: `02_PRODUCT_REQUIREMENTS.md`
- Architecture: `04_TECHNICAL_ARCHITECTURE.md`
- Design system: `06_UX_CONTENT_AND_DESIGN_SYSTEM.md` and approved Stitch screens
- Security: `08_SECURITY_PRIVACY_AND_COMPLIANCE.md`
- Build workflow: `09_ANTIGRAVITY_BUILD_INSTRUCTIONS.md`
- Agent behaviour: `13_ANTIGRAVITY_AGENT_INSTRUCTIONS.md`

The documents are provided as-is from the available FactoryOS documentation set. Review any overlapping or conflicting instructions before implementation.
