# Stitch Prompt — Clickable Prototype Flows

Connect the screens into these clickable journeys. Keep the prototype realistic and use illustrative data.

## Flow 1: Owner checks factory health
Login → Owner Overview → Needs Attention → Delayed Job Detail → Job Progress → Return to Overview.

Success: owner understands which job is delayed and who owns the next action.

## Flow 2: Supervisor records production
Login → Supervisor Home → Today's Jobs → Select Job → Add Production → Review → Save Success → Updated Job Card.

Success: a common production update is understandable without training.

## Flow 3: Supervisor marks attendance
Supervisor Home → Attendance → Mark all present → Change absent/late exceptions → Review → Save → Attendance Summary.

Success: no accidental bulk save without review.

## Flow 4: Report machine problem
Supervisor Home → Report Issue → Select Machine → Category/Severity → Description → Submit → Issue Detail.

Success: owner can see the issue and its current state.

## Flow 5: Owner reads Factory Pulse
Owner Overview → Factory Pulse → Daily Report Detail → Production Breakdown → Open Issues.

Success: every headline metric can be traced to supporting records.

## Flow 6: Offline production entry
Supervisor Home → Offline indicator → Add Production → Save Locally → Pending Sync state → Sync Success.

Success: user understands that record is not yet on server and can see its sync status.

Do not create dead-end buttons. All primary buttons must navigate or produce a meaningful state change.
